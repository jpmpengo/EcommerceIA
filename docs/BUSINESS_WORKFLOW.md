# Cycle de vie d'une opportunité

## 1. Détection

Une opportunité est détectée.

Statut :
- detected

## 2. Analyse

Le collaborateur analyse :

- marge
- demande
- concurrence

## 3. Validation

Le commerçant approuve.

Statut :
- approved

## 4. Décision

Trois décisions possibles :

### Publier

Conséquences :
- création du produit
- statut = published

### Reporter

Conséquences :
- postponed_until = +14 jours

### Rejeter

Conséquences :
- statut = rejected
- conservation dans l'historique
